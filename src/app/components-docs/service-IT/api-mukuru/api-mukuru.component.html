Introduction

L'API Mukuru permet d'effectuer différentes opérations de retrait d’argent via des requêtes HTTP. Cette documentation décrit les endpoints disponibles, les paramètres requis et les réponses attendues.

1. Charger un bon (loadVoucher)

Ce endpoint permet de charger un bon Mukuru à partir de son code, et de récupérer les informations nécessaires à l’identification du bénéficiaire et à la préparation du paiement.

  • Méthode : POST
  • URL : (Domaine)/mukuru/loadVoucher
